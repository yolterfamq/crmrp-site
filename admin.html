Админка сайта

Войди под своим админским логином.

Вставь ключ доступа GitHub. Он хранится только в этом браузере.

Где взять ключ
  1. Открой github.com → Settings → Fine-grained tokens → Generate new token.
  2. Name: CRM админка. Expiration — сколько хочешь (например, 1 год).
  3. Repository access → Only select repositories → crmrp-site.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token → скопируй ключ и вставь сюда. Никому его не показывай.
