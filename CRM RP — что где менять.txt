=====================================================================
  CRM RP — ЧТО ГДЕ МЕНЯТЬ
  (все пути — от Рабочего стола)
=====================================================================

Открывать файлы можно Блокнотом: правый клик → «Открыть с помощью» → Блокнот.
Главное правило: меняй только текст в кавычках и цифры. Запятые, скобки
и кавычки вокруг не трогай — из-за лишней или потерянной запятой всё ломается.


---------------------------------------------------------------------
 1. САЙТ  (папка «CRM RP Site»)
---------------------------------------------------------------------
Почти всё меняется в ОДНОМ файле:  CRM RP Site\assets\site.config.js

  download        — ссылка на установщик (не трогай, она правильная)
  launcherVersion — версия лаунчера внизу сайта, например '1.0.2'
  gameSize        — сколько весит игра
  forum           — ссылка на форум (пусто '' = «скоро»)
  discord, vk, telegram, youtube — соцсети (пусто '' = кнопки нет)
  servers         — серверы: name — название, status:
                    'open' — работает, 'soon' — скоро, 'later' — позже

ПОПОЛНЕНИЕ (страница donate.html) — там же, в блоке  shop: [ ... ]
  Каждая карточка — одна строка:
    { name: 'Любая машина', icon: '🚗', price: 0, desc: 'Любой автомобиль из игры' },

  • Поменять цену:   price: 0  →  price: 500     (0 = «Цена скоро»)
  • Валюта:          currency: '₽'  (внизу блока)
  • Убрать карточку: удали всю её строку целиком, вместе с запятой в конце.
  • Добавить:        скопируй любую строку, вставь ниже и поменяй текст.
                     icon — любой смайлик, desc — короткое описание.
  • Новый раздел:    скопируй блок  { group: 'Для игры', items: [ ... ] },
                     и поменяй название group.

Тексты страниц (заголовки, инструкция «Как начать играть», блок про антивирус)
лежат в  CRM RP Site\index.html  — ищи нужную фразу через Ctrl+F и меняй.

ПОСЛЕ ЛЮБЫХ ПРАВОК САЙТА → запусти  CRM RP Site\Выложить сайт.bat
Через 1–2 минуты изменения будут в интернете. В браузере нажми Ctrl+F5.


---------------------------------------------------------------------
 2. ЛАУНЧЕР — то, что меняется БЕЗ пересборки и БЕЗ перезапуска
---------------------------------------------------------------------
Новости, ссылки и уведомления лаунчер берёт С САЙТА, из папки
  CRM RP Site\launcher\
Поменял файл → «Выложить сайт.bat» → у всех игроков лаунчер обновит это сам
(сразу при запуске или в течение 5 минут, если лаунчер уже открыт).

  launcher\news.json  — «Последние обновления» над загрузкой (показываются первые 3)
      {
        "tag": "Обновление",              ← маленькая надпись над заголовком
        "date": "2026-10-19",             ← дата (год-месяц-день)
        "title": "Новый лаунчер CRM RP",  ← заголовок
        "text": "...",                    ← текст
        "image": "",                      ← КАРТИНКА (см. ниже)
        "url": "https://..."              ← куда ведёт клик (пусто "" = никуда)
      },
      Новая новость — скопируй блок { ... }, вставь ПЕРВЫМ в список.
      Между блоками запятая, после последнего — без запятой.

      ФОТО К НОВОСТИ: положи картинку в  CRM RP Site\launcher\img\
      (например  update1.jpg, лучше широкую, примерно 600×300) и напиши:
        "image": "https://yolterfamq.github.io/crmrp-site/launcher/img/update1.jpg"
      Без картинки ("image": "") лаунчер рисует ночной город сам.

  launcher\launcher.json — ссылки кнопок в лаунчере:
      "site"    — Сайт          "forum"   — Форум
      "donate"  — Пополнение    "news"    — «Все новости»
      "discord", "vk", "telegram", "youtube" — значки соцсетей
      "notice"  — строка-объявление в лаунчере (пусто "" = не показывать;
                  появляется при следующем запуске лаунчера)

  launcher\notifications.json — колокольчик в лаунчере:
      { "id": 2, "date": "2026-10-20", "title": "...", "text": "..." }
      У каждого НОВОГО уведомления id должен быть больше прошлых —
      по нему лаунчер понимает, что уведомление новое, и зажигает колокольчик.


---------------------------------------------------------------------
 3. ЛАУНЧЕР — то, что требует новой версии
---------------------------------------------------------------------
Папка «CRIMINAL RP Launcher». Нужно, если меняешь сам лаунчер: внешний вид,
кнопки, адрес сервера (IP), что и куда он качает.

  config.json  → "server": { "host": "IP", "port": 22003, "httpPort": 22005 }
                 сюда впишешь IP своего сервера, когда будет.
                 IP не попадает на сайт — только внутрь лаунчера.

КАК ВЫПУСТИТЬ НОВУЮ ВЕРСИЮ:
  1. package.json → "version": "1.0.2"  → подними на 1.0.3 (всегда больше прошлой!)
  2. Запусти  «5. Собрать и выложить лаунчер.bat»
  3. В CRM RP Site\assets\site.config.js поменяй launcherVersion на ту же
     и запусти «Выложить сайт.bat»
У игроков лаунчер сам скачает обновление в фоне и предложит «Перезапустить».


---------------------------------------------------------------------
 4. КЛИЕНТ ИГРЫ (файлы GTA/MTA)
---------------------------------------------------------------------
Поменял что-то в папке  CRIMINAL RP  →  запусти
  «CRIMINAL RP Launcher\3. Залить клиент на GitHub.bat»  с НОВЫМ номером (3, 4, ...).
Зальются только изменённые файлы. Лаунчер у игроков докачает их перед игрой.


---------------------------------------------------------------------
 5. DISCORD-БОТ CRM BOT  (папка «ПРОЕКТЫ\CRM BOT»)
---------------------------------------------------------------------
  Магазин (прайс-лист админок) — пульт → «🛒 Магазин»: двойной щелчок по ячейке,
       поменять название/цену/описание → «Сохранить в Discord».
  Правила — файл rules.txt, потом в Discord команда  !panels
  Ссылки на сайт и установщик, сколько каналов ожидания/обзвона —
       config.json, потом перезапуск бота и  !setup
  Названия ролей и каналов — crm_layout.py (только текст в кавычках),
       потом перезапуск бота и  !setup
  Защита — пульт → «Защита» (галочки) или команда  !security
